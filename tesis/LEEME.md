# Documento LaTeX (Overleaf)

Compilador: pdfLaTeX. Bibliografía: biblatex con backend bibtex (`bibliothesis.bib`).
Para usar la plantilla original, añadir `MastersDoctoralThesis.cls`; si no está, `fallback_thesis.tex` reproduce su diseño.
Las tablas de `Tablas/` y las figuras de `Figures/` las genera `08_latex.py` del código del estudio; no se editan a mano.
